# Rebuttal experiment plan

The primary A3/A2/A4/A5 generation uses the iteration-100 archived checkpoint as a **controlled frozen-policy probe**, not as a replay of the unknown training run. X extends this same fixed protocol to iterations 50 and 150 if the timed-smoke gates fit the cutoff. Prompts are sampled without replacement from the local MATH validation dataset with Python seed 42; the first eight in that fixed 32-prompt sample form the smoke subset. The prompt template is `gear/configs/prompt_library/qwen_MATH.jsonnet`; sampling uses temperature 0.6, top-p 0.95 and max-new-tokens 1024. Individual request seeds are recorded in `controlled_prompt_manifest.json`. Run settings remain unknown; GEAR defaults used by any proxy are labeled source-snapshot defaults.

## Interpretation limits

The archive does not establish training-time settings or training-tree behavior. No new probe result will be attributed to the archived training trajectory. `R_a` selects oracle allocations and `R_b` evaluates them; they must remain disjoint. Bootstrap resampling is by prompt, because several nodes share each prompt. RTX 3090 seconds describe this local diagnostic only. Lower `J`, `L_node`, or `L_heldout` is not evidence of lower full clipped-PPO gradient error or higher benchmark accuracy.
