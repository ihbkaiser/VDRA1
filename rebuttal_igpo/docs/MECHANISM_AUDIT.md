## Additional checks

- **Zero-child allocation:** `gear_inference_strategy.py::_finalize_empty_expansion_node` marks the node a leaf, scores its existing text with the task reward function, and sets `reward_std=0`. The node remains in its parent's `children`, so its incoming edge can be emitted by `extract_edges_from_tree`, subject to edge filters.
- **Trainer whitening:** `trainers/ppo_trainer.py` defaults `whiten_advantages=True`; when precomputed advantages are supplied, `compute_loss` applies `masked_whiten` if the resolved run config retains that default. The actual run flag is unknown.
- **Iteration/checkpoint mapping:** `runtime/policy_iteration_runtime.py` passes `iteration_id` and `latest_policy_path` to episode generation before calling `trainer.step`. On a fresh run, iteration 0 uses the initial model; the path returned by training step i is then used for iteration i+1. The missing archive logs prevent confirming this mapping for these checkpoints.
